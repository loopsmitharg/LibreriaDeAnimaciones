Conector a Google Apps Script

Origen: GameOver · torneos/index.htmljs/main.js → cargarCupos · actualizarDOM · submit de .embedded-reg-form · calcularSubtotalfetch, sin dependencias

Cómo funciona

  • Leer (GET): fetch(API_URL + "?t=" + Date.now()). El ?t= evita la caché. El servidor responde { lol: { restantes: 12 }, … } y actualizarDOM() reescribe solo el texto que cambió.
  • Polling: cada 40s y solo con la pestaña visible; al volver a la pestaña se refresca enseguida.
  • Escribir (POST): el cuerpo es JSON pero con Content-Type: text/plain. Así es un "simple request" y el navegador no manda el preflight OPTIONS, que Apps Script no sabe responder. redirect: "follow" sigue el salto a googleusercontent.com.
  • El servidor responde { status: "success", nuevos_cupos } y los cupos se actualizan sin esperar al próximo polling.

Para usarlo con tu planilla

  • En script.js poné tu URL en API_URL (la de "Implementar → Aplicación web", termina en /exec). Vacía, la demo usa mock-servidor.js y no envía nada.
  • Code.gs es una plantilla del lado servidor (doGet / doPost) con el mismo contrato. Es una reconstrucción: el .gs real de GameOver no está en el repositorio.
  • Los precios viven en BASE_PRICES (Object.freeze) y la cantidad se sanea con un máximo por torneo. Igual el servidor tiene que recalcular el monto: el cliente se puede manipular.
  • Feedback: alerta dentro del form, botón deshabilitado con "Enviando..." y reset a los 5s.
