Ficha técnica

Cursor con inversión de color

Origen: CosmeCV · index.html (.cursor / .cursor-dot)js/main.js → initCursorGSAP (quickTo)

Cómo funciona

  • El anillo tiene borde ácido y mix-blend-mode: difference: resta su color del fondo, así invierte texto e imágenes que pasan por debajo.
  • En estado activo se rellena con el color papel y pasa a exclusion: la palabra de abajo se lee invertida dentro del círculo.
  • Sigue al puntero con gsap.quickTo: el anillo con 0.45s de inercia, el punto con 0.1s (casi pegado).
  • Al entrar en a, button, summary, [data-cursor] crece y muestra la etiqueta de data-cursor (o GO / OPEN).

Para reutilizar

  • Se inicializa solo si hay GSAP, (hover: hover) and (pointer: fine) y no hay reduced-motion.
  • Para que la inversión funcione, el cursor no puede quedar dentro de un ancestro con isolation: isolate o transform: va como hijo directo del body.
  • El tamaño cambia con transición CSS de width/height y margin (el centro no se mueve).
  • Elementos agregados después de la carga no tienen listeners: volver a llamar a la función o delegar.
