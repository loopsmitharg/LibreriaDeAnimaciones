Navegador de productos 3D (overlay)

Referencia: zentry.com → menú "Products"Reconstrucción propia: ni código ni arte del sitioGSAP + CSS 3D + scroll-snap

Cómo funciona

  • El overlay es un contenedor con scroll propio y scroll-snap: cada producto es una parada. Adentro, un pin sticky de 100vh muestra la escena (igual que el original, que usa un scroller con position: sticky).
  • t = scrollTop / paso es un índice continuo (1.37 = entre el 2 y el 3). Un gsap.quickTo lo suaviza y todo se dibuja desde ese único valor: lista, tarjetas y textos van siempre sincronizados.
  • Tarjetas: para cada una, d = índice − t. Si d ≥ 0 espera a la derecha (x = d·1.08 anchos, hacia atrás en z, rotateY(d·26°)); si d < 0 sale por la izquierda casi de canto (rotateY(d·78°)). Todo dentro de un escenario con perspective e inclinado.
  • Lista: se desplaza para centrar el título activo (interpolando entre las posiciones medidas de cada ítem) y su color pasa de violeta a blanco según la cercanía.

Para reutilizar

  • Los productos son el HTML: un .pnav__item y una .pcard por producto, en el mismo orden. La descripción sale de data-* de cada ítem.
  • NEXT y PREV (en script.js) y la inclinación del escenario (--stage-tilt) definen el recorrido de las tarjetas.
  • Abrir: el fondo funde, la lista sube en cascada y las tarjetas llegan desde abajo girando. Mientras está abierto se bloquea el scroll de la página y el foco queda en el diálogo.
  • El arte de las tarjetas es solo CSS (esferas y tramas). En un proyecto real va una imagen, un video o un canvas dentro de .pcard__art.
  • La fuente Anton viene de Google Fonts: es la única pieza de la librería que no es 100% local.
