Scroll manual: rueda con riel arrastrable

Origen: Loop Smith · index.html (Work Smarter)js/main.js → buildWorkWheel · paintPhilosophyGSAP + ScrollTrigger

Cómo funciona

  • Cada panel tiene un t (-1 entrando, 0 al centro, +1 saliendo) y se ubica sobre una elipse: x = (cos(-t·SWEEP) - 1)·rx, y = sin(-t·SWEEP)·ry.
  • KNOTS mapea scroll → escena con mesetas: cada paso descansa un rato al centro.
  • El riel es un trazo SVG con stroke-dashoffset. Se muestrea una vez (141 puntos) en coordenadas del pin: el cabezal y el arrastre consultan la tabla, sin medir el path por frame.
  • Arrastrar el cabezal convierte la Y del puntero en progreso (progressAtY) y hace scrollTo: el scroll sigue siendo la fuente de verdad.
  • La frase del paso 3 se "pinta" palabra por palabra interpolando colores con el progreso.

Para reutilizar

  • SWEEP y ROTATION controlan cuánto gira cada panel.
  • El alto de .work-wheel (280svh) es el presupuesto de scroll.
  • Mientras se arrastra se saltea el scrub: el cabezal debe seguir al puntero, no ir 0.68s atrás.
  • Debajo de 901px no hay pin: los paneles entran con un fade al aparecer.
  • El cabezal es un role="slider" con teclado (flechas, Re Pág/Av Pág, Inicio/Fin).
