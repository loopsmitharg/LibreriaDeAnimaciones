Cómo funciona

  • Cada escena es un <svg> a pantalla completa con un <mask>: fondo negro (oculta) + un grupo [data-mask] de rectángulos blancos (muestran). Al principio los rectángulos miden 0 o tienen opacidad 0, así que la escena es invisible.
  • El viewBox se recalcula a 100 × (alto/ancho·100): una unidad SVG es 1% del ancho, y las franjas cubren justo la pantalla sin deformarse.
  • Persianas: cada franja son dos rectángulos que nacen en su línea central y crecen hacia afuera (attr: { y, height } o { x, width }) con stagger. Grillas: celdas que pasan de opacidad 0 a 1 en orden aleatorio (gsap.utils.shuffle), o columna por columna.
  • Un único timeline con scrub encadena: abrir máscara 1 → entra texto 1 → sale texto 1 → abrir máscara 2… Las escenas se apilan, así que cada máscara destapa la nueva por encima de la anterior.

Para reutilizar

  • Cambiá el arte por una foto: dentro del <g mask> poné <image href="foto.webp" width="100%" height="100%" preserveAspectRatio="xMidYMid slice" />.
  • Las variantes están en el objeto VARIANTES de script.js: cada una tiene build() (crea los rectángulos) y open() (devuelve el tween). Sumar una nueva es agregar una entrada.
  • Cantidad de franjas/celdas: FRANJAS_H, FRANJAS_V y columnasGrilla(). Duración del recorrido: height de .mstage (500vh).
  • Al redimensionar se reconstruyen las máscaras (con debounce). Sin GSAP o con prefers-reduced-motion las escenas quedan apiladas en flujo, visibles y con su texto.
  • El original usa Lenis para suavizar el scroll; acá alcanza con scrub: 1.5 y scroll nativo.
