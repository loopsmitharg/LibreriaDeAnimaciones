Tablero de datos con barras animadas

Origen: Loop Smith · tableros-de-datos/index.htmljs/servicios.js → dashboardDemo · initializeServiceDemosGSAP

Cómo funciona

  • Cada barra está dibujada por CSS con transform: scaleX(var(--v)) (columnas: scaleY, desde abajo).
  • GSAP anima fromTo de 0 al valor, leído con una función: scaleX: (i, el) => --v de la fila.
  • Ranking y columnas con stagger: 0.07; la barra apilada se abre de izquierda a derecha; las notas entran al final.

Para reutilizar

  • Solo se anima transform y opacity: nunca width/height.
  • La barra apilada usa flex: var(--v) en cada segmento: los porcentajes son los propios --v.
  • Los colores de alerta (.is-low, .is-alert) son solo clases.
  • El botón "Repetir" es un agregado de la librería para volver a ver la animación.
