    Typography Playground: 30 animaciones sobre el logo de Loop Smith

    HTML · CSS · JavaScriptGSAP 3.12.5 + ScrollTriggerSin frameworks ni WebGLContornos: Outfit 700 (OFL)

    Cómo está armado

    • core/logo-data.js: geometría del lockup generada desde la fuente (tools/build-logo-data.py). Cada letra es un contorno real de Outfit 700, con el kerning y el espaciado del lockup del sitio.
    • core/logo.js: Master Logo. Renderiza el lockup con una pieza por carácter y lo restaura exacto.
    • core/kit.js: ciclo de vida, física, puntero, arrastre, poses y escenas de scroll aisladas.
    • effects/NN-nombre.js: una animación por archivo, con play / pause / reset / destroy.

    Qué tocar para reutilizar

    • Copiar core/ y los effects/ que hagan falta, más GSAP (y ScrollTrigger para las de scroll).
    • El contenedor define el tamaño: la animación ocupa el 100% de su ancho y alto.
    • Colores con --lst-accent, --lsl-ink y --lsl-accent en el contenedor.
    • Las escenas de scroll usan la ventana por defecto; con { scroller: elemento } quedan encapsuladas.
    • Con prefers-reduced-motion se muestra el logo completo y quieto.
